BIRTHDAY SYSTEM.exe — website ucapan ulang tahun

FILE:
- index.html (website satu halaman, semua CSS/JavaScript sudah di dalamnya)

CARA ONLINE GRATIS DENGAN GITHUB PAGES:
1. Login atau daftar akun GitHub.
2. Buat repository baru, misalnya: birthday-surprise
3. Pilih Public, lalu Create repository.
4. Upload file index.html ke repository (Add file > Upload files > Commit changes).
5. Buka Settings > Pages.
6. Pada bagian Build and deployment, pilih Deploy from a branch.
7. Pilih branch main dan folder /(root), lalu Save.
8. Tunggu proses selesai. Link biasanya berbentuk:
   https://USERNAME.github.io/birthday-surprise/

Ganti USERNAME dengan username GitHub milik Anda. GitHub yang menerbitkan link; file ini belum di-hosting secara online otomatis.

PERSONALISASI:
Edit index.html lalu cari teks ucapan di bagian <section id="message">. Anda bisa mengganti kata-kata sesuai nama/panggilan orang yang berulang tahun.
